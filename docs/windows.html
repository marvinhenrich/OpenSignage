Was das Paket macht

Die Anzeigegeräte laufen als echter Windows-Kiosk (Assigned Access) mit Edge im Vollbild: kein Desktop, keine Taskleiste, Alt+Tab und Tab-Wechsel gesperrt. Ein Paket, einmal einer Gerätegruppe zugewiesen — jedes Gerät wird damit identisch und von Grund auf eingerichtet, egal in welchem Zustand es vorher war.

ZertifikatDas CMS-Zertifikat wird als vertrauenswürdig hinterlegt.
Kiosk-KontoEigenes lokales Konto mit eigenem Zufallskennwort je Gerät.
AnmeldungAutomatisch, vor und nach der Kennwortänderung geprüft.
Geräte-GeheimnisJe Gerät erzeugt, in C:\ProgramData\<Name>\device.key.
ZeitschaltungEin- und Ausschaltzeiten als geplante Aufgabe.
GeräteagentMacht Neustart und Herunterfahren aus dem CMS möglich.

Warum es einen Agenten braucht

Der Player ist eine Webseite. Sie kann sich neu laden, aber den Rechner nicht neu starten — und im Edge-Kiosk gibt es keine Brücke zum Betriebssystem. Ohne Agent verpuffen Neustart und Herunterfahren aus dem CMS wirkungslos.

Der Agent läuft als geplante Aufgabe unter SYSTEM, jede Minute, und beendet sich sofort wieder. Kein Dienst, kein Dauerprozess.

Bewusst konservativ. Der Server liefert jeden Befehl genau einmal aus und verwirft ihn nach fünf Minuten. Der Agent merkt sich zusätzlich die zuletzt ausgeführten Vorgänge und erlaubt höchstens einen Neustart je zehn Minuten. Selbst wenn Server oder Netz Unsinn liefern, kann daraus keine Dauerschleife werden.

Identität eines Geräts

Ein Display wird über den Rechnernamen identifiziert, nicht über einen Zufallswert im Browserspeicher. Deshalb bleibt die Kopplung über Neustarts und Profil-Zurücksetzungen erhalten — Assigned Access wischt das Edge-Profil regelmäßig.

Dazu kommt ein Geräte-Geheimnis. Der Server speichert nur dessen SHA-256-Abdruck und bindet es beim ersten Kontakt. Danach kann sich kein fremdes Gerät als ein bereits bekanntes ausgeben. Für den Gerätetausch gibt es ein Zurücksetzen, das nur Administratoren auslösen können.

Ausrollen

  1. Paket im CMS unter Anleitung herunterladen.
  2. In die Softwareverteilung importieren.
  3. Einer Gerätegruppe zuweisen — nicht einzelnen Geräten, sonst wird es unübersichtlich.
  4. Verteilen. Nach dem Neustart meldet sich das Gerät mit einem Kopplungscode.
  5. Im CMS unter Displays freigeben.

Das Paket ist wiederholbar: bei jeder erneuten Installation wird das Gerät auf denselben Zustand gezogen. Protokoll am Gerät unter C:\ProgramData\<Name>\install.log, auch ohne Administratorrechte lesbar.
